# Maintaining Sparkles

This repository is the dedicated diamond research and evaluation archive. Read `CONVENTIONS.md` and `Sparkles home.md` before editing.

Use `research-igi-diamond` for research and `evaluate-asscher` for optical assessment. Their archive contract routes to this repository, not Knowledge.

Preserve certificate identity, original evidence bytes and dated report history. Keep links within this repository. Use focused branches and pull requests; do not merge without an explicit request. Verify YAML, local links, artifact manifests and uploaded bytes before reporting success.

## Website navigation

`index.html` is the GitHub Pages entry point. When adding a diamond or evaluation, update its card, verified facts, latest report link and expandable assessment history. Link visual HTML reports and evidence downloads with relative paths so they work under the `/sparkles/` project URL. Link Markdown dossiers to their GitHub file pages for readable rendering. Preserve earlier assessment links and original-image provenance. Update the visible counts, search metadata and archive snapshot date. Verify every target exists; keep the static cards usable without JavaScript.
