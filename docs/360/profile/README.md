# Retained descriptor profile

Issue #45 defines the stable hand-off from the #20 descriptor programme to #22
empirical calibration.

The production contract is `diamond360-descriptor-profile/1`. It is a
**consolidation layer only**: the builder reads already-committed benchmark
summaries and does not recalculate photometry, masks, traces, thresholds, or
optical measurements.

## Rules

- The exact production vocabulary is declared in
  `diamond360.descriptor_profile.FIELD_SPECS`; disposition files are evidence,
  not automatic feature discovery.
- Every production value uses the exact wrapped 17-source-step core:
  `248..255,0..8`.
- Validity remains `ok | review | unavailable` with machine-readable reasons.
- `review` values remain numeric; unavailable values are JSON `null`.
- Outer, semantic, dynamic/pair-local, REVISE and REJECT candidates are not
  production fields.
- Support fractions are provenance/QC, not optical metrics.
- There are no aesthetic thresholds, weights, excellent/good/poor labels or
  composite scores.

## Roles

`measurements` are legitimate inputs for #22 calibration. `context` is
needed to interpret a measurement but must not be treated as an independent
feature. Upstream sensitivity/QC remains reachable through `audit_refs`.

The only context field in version 1 is morphology active-frame fraction.

## Redundancy groups

`activity_motion` groups activation excursion with contrast mobility: they are
related descriptions of movement and are not additive quality points.

`relative_dark_state` groups occupancy with switching: they use the same
relative-dark state definition and must not be counted as independent votes.
Dark persistence remains a separate temporal-structure descriptor.

## Production vocabulary

- whole-stone fixed raw activation total excursion;
- centre/inner/middle coarse-fixed relative activation total excursion;
- centre/inner/middle coarse-fixed relative median mobility;
- centre/inner/middle coarse-fixed mean relative-dark occupancy at k=0.65;
- coarse-fixed inner dark Q90 persistence;
- coarse-fixed inner/middle switching rate at k=0.65;
- coarse-fixed centre-inner and inner-middle Pearson coordination;
- fixed coarse-whole E-W, N-S, NE-SW and NW-SE Pearson coordination;
- fixed-support median largest-component fraction;
- context only: morphology active-frame fraction.

## Build

```bash
python -m diamond360.descriptor_profile --repository . --output docs/360/profile
```

The command writes one JSON per benchmark stone plus `comparison.json` and a
wide `comparison.csv`. Rebuilding is deterministic; committed artifact tests
compare generated bytes directly.

`comparison.csv` keeps one value, status and reasons column per field so
validity is never silently flattened away.

See `schema.json` for the machine-readable envelope and
`docs/360/SCHEMA.md` for the repository-wide schema catalogue.
