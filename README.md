# Sparkles

Diamond research, original evidence and dated Asscher evaluations.

Open this repository as an Obsidian vault and start at `Sparkles home.md`.

- `resources/<LAB>-<REPORT>/`: certificate-keyed dossiers and artifacts.
- `evaluations/`: dated visual HTML reports and Markdown companions.

Research and evaluation preserve source links, evidence limitations and report history. Updates use focused pull requests; merging requires an explicit request.

## 360 preprocessing

The Python package provides auditable frame ingestion, silhouette/geometry QC,
centre/scale registration, conservative photometry and exploratory temporal maps.
Start with [the CLI and methodology guide](docs/360/README.md). It does not score
Asscher quality. Persistent implementation/resume log: [#12](https://github.com/choonkiatlee/sparkles/issues/12).
